# VocabVoice — Free Voice Vocabulary Coach

A zero-cost prototype for a hiring assignment.

## Features
- Browser text-to-speech
- Browser speech recognition
- Vocabulary lessons
- Sentence practice
- Instant feedback
- Next-word flow
- No paid API keys or backend required

## Run
Open `index.html` in a modern browser. Google Chrome is recommended because SpeechRecognition support varies by browser.

## Deploy free
Create a public GitHub repository, upload `index.html`, then enable GitHub Pages from Settings → Pages → Deploy from a branch → main → / (root).

The deployed URL will look like:
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

## Note
The prototype intentionally uses the browser's Web Speech APIs rather than a paid voice/LLM API, keeping the demo at ₹0 cost. Speech recognition availability varies by browser/device.
